# Мониторинг падения цен на акции на международных рынках

Прогнозно-аналитическая система (дисциплина «Прогнозно-аналитические системы», профиль «Управление данными»).
Этап 1: источники данных и обработка данных. Веб-дашборд читает CSV-витрины из `data/mart/`.

## Быстрый старт

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python -m pipeline run          # загрузка → staging → витрины (одна команда)
python -m pipeline status       # журнал последних загрузок
pytest -q                       # тесты
```

Повторный запуск догружает только новые данные. Параметры — `config/config.yaml`,
папку CSV можно переопределить через `PAS_DATA_DIR`, конфиг — через `PAS_CONFIG`.
Расписание: cron, например `0 7 * * 1-5 cd /path/to/project && .venv/bin/python -m pipeline run`.

## Дашборды в браузере

После установки зависимостей запустите приложение из корневой папки проекта:

```bash
python -m pipeline run             # загрузить источники и пересобрать CSV-витрины
python -m streamlit run app.py
```

Streamlit откроет дашборд в браузере (обычно по адресу `http://localhost:8501`).
Если браузер не открылся автоматически, скопируйте этот адрес в браузер. На странице
доступны монитор падений, история скорректированных цен и новости; таблицы можно
фильтровать по стране и сектору.

Дашборд читает CSV-файлы из `data/mart/` без кэширования и перечитывает их каждые
60 секунд. Поэтому после обновления данных командой `python -m pipeline run` открытая
страница отобразит новые данные не позднее чем через минуту. Если витрины ещё не
созданы, сначала выполните эту команду. Для отдельного расположения CSV задайте
`PAS_DATA_DIR` так же, как при запуске конвейера. При необходимости остановите
сервер сочетанием `Ctrl+C` в терминале.

## Источники (разнородные)

| Источник | Способ получения | Формат | Загрузка |
|---|---|---|---|
| Yahoo Finance, цены OHLCV | библиотека yfinance (API) | таблица | инкремент по водяному знаку `max(date)` |
| Yahoo Finance, новости | библиотека yfinance | вложенный JSON, текст | накопление снимков, дедупликация по `(ticker, link)` |
| FRED: VIX, доходность 10-летних облигаций США | HTTP GET | CSV | инкремент по водяному знаку |
| `data/reference/companies.csv` | файл | CSV | справочник: страна, биржа, сектор, валюта |

## Слои хранения (CSV)

Каждая таблица хранится как отдельный CSV-файл в `data/<слой>/`. Например,
цены — `data/raw/prices.csv`, итоговый монитор — `data/mart/mart_drawdown_monitor.csv`.
Справочник компаний остаётся в `data/reference/companies.csv`.

| Слой | Ответственность |
|---|---|
| `raw` | полученные данные и поля `_load_id`, `_loaded_at` |
| `ref` | справочники, в том числе `company.csv` |
| `stg` | очищенные данные и `prices_rejected.csv` с причинами отбраковки |
| `mart` | аналитические витрины: цены, новости, календарь и монитор падений |
| `meta` | `load_log.csv` — журнал загрузок |

Преобразования и расчёты выполняются pandas; SQL-движок не используется.
Происхождение показателя: `mart/mart_drawdown_monitor.csv` ←
`mart/fact_price_daily.csv` ← `stg/prices.csv` ← `raw/prices.csv`.
Существующий `data/warehouse.duckdb` не удаляется и автоматически не импортируется:
CSV-хранилище начнёт с пустых таблиц, а историю нужно заново получить из источников
или предварительно экспортировать отдельно.

## Надёжность

- **Инкрементальность:** старт с `max(date) − overlap_days`; первая загрузка — с `start_date`.
- **Идемпотентность:** естественные ключи при обновлении CSV; staging и mart пересобираются из raw.
- **Устойчивость:** повторы с растущей задержкой, отдельная пауза при «Too Many Requests», таймаут запроса, сбой одной сущности не останавливает остальные, пустой ответ при первой загрузке считается ошибкой, зависшие запуски помечаются `aborted`.
- **Журнал:** `meta.load_log` — запуск, источник, сущность, статус, диапазон дат, число полученных и вставленных строк, число попыток, текст ошибки.
- **CSV-путь:** по умолчанию `data/`; альтернативную папку задаёт `PAS_DATA_DIR`.

## Ограничения

- Yahoo Finance — неофициальный источник без гарантий доступности и лимитов.
- После выплаты дивидендов провайдер пересчитывает `Adj Close` за всю историю. Для полного пересчёта используйте `python -m pipeline run --full-refresh` (upsert безопасен).
- Цены бумаг на разных биржах в разных валютах (у `HSBA.L` — в пенсах); все показатели считаются в процентах, поэтому сопоставимы.
- Новости: провайдер отдаёт только последние ~10 штук на тикер.
- CSV удобен для небольших проектов и совместимости, но не обеспечивает транзакций,
  индексов, параллельной записи и быстрых запросов по крупным объёмам. При росте данных
  следует рассмотреть DuckDB или другую СУБД.
